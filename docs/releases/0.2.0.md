OG-Host 0.2.0

Accounts and security
- Users in two realms (OG-Host accounts, Linux system accounts), groups, roles, permissions per path, API tokens with separated privileges.
- Two-factor sign-in (authenticator app + recovery codes), sign-in lockouts, audit log.
- Host firewall that can't lock you out: changes go back by themselves unless you keep them.

Storage and backups
- Deduplicated, compressed, optionally encrypted backups of stacks, containers and VMs.
- Datastores on this server, NFS or SMB; backup jobs with schedules and retention; restore in place or to a folder; browse and download single files; verify and garbage collection.

Virtual machines
- QEMU/KVM with UEFI, Secure Boot and TPM 2.0 (Windows 11), virtio/SATA/SCSI/NVMe disks, ISO upload, snapshots, PCI and USB passthrough.
- A console in the browser; VMs get their address from OG-Host's own DHCP on its networks, or sit straight on the LAN.
- "Looks like a real PC": hides the hypervisor from the guest.

Clusters
- Join servers at different sites over mutual TLS; shared accounts; manage every node from any node.
- Sync jobs copy backups to another site (only what's missing; encrypted stays encrypted).

Updates
- Signed releases from one or more mirrors; automatic rollback if a new version doesn't stay up; rolling updates across a cluster; system package updates.
